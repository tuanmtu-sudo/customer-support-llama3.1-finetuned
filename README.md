  # customer-support-llama3.1-finetuned
  # Customer Support AI Assistant - Fine-tuned Llama 3.1 8B

A specialized customer support chatbot fine-tuned from **Meta-Llama-3.1-8B-Instruct** using **QLoRA**.

This model is trained to handle common customer service scenarios professionally, empathetically, and helpfully.

### 📊 Model Details
- **Base Model**: Meta-Llama-3.1-8B-Instruct
- **Fine-tuned Model**: [victor-tu-customer-support-llama3.1-8b](https://huggingface.co/victor-tu-customer-support-llama3.1-8b)
- **Method**: QLoRA (PEFT)
- **Dataset**: Bitext Customer Support LLM Training Dataset
- **Training Framework**: Unsloth + Hugging Face TRL
- **Parameters**: 8 Billion
- **Training Steps**: 100 (initial version)

### 🎯 Key Capabilities
- Order tracking and status updates
- Return and refund processing
- Delayed shipment handling
- Product information and troubleshooting
